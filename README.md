# Sudoku Master

Sudoku Master is a browser-based Sudoku game built with HTML, CSS, and JavaScript. It offers a clean interface and a simple way to enjoy Sudoku, with multiple difficulty levels and helpful tools to make solving puzzles easier.

## Features

- **Multiple Difficulty Levels** — Choose between Easy, Medium, and Hard.
- **New Game** — Generate a new puzzle whenever you want.
- **Reset Board** — Restore the current puzzle to its original state.
- **Pencil Mode** — Add candidate numbers to empty cells while solving.
- **Hint System** — Reveal the correct number for a selected cell.
- **Erase Option** — Remove a number from an editable cell.
- **Timer** — Track the time spent solving each puzzle.
- **Mistake Counter** — Keep track of incorrect entries.
- **Board Validation** — Check your entries against the puzzle solution.
- **Keyboard Support** — Enter numbers and navigate the board using your keyboard.
- **Responsive Layout** — Play on desktop and mobile screens.

## Built With

- HTML5 — Page structure
- CSS3 — Styling and responsive layout
- JavaScript — Puzzle generation and game logic

## Getting Started

You can run Sudoku Master locally without installing any additional dependencies.

### Prerequisites

- A modern web browser
- Git, if you want to clone the repository
- Visual Studio Code (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kushithp/Sudoko.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Sudoko
   ```

3. Open the project folder in Visual Studio Code, or open `index.html` directly in your browser.

4. Alternatively, use the Live Server extension in VS Code for a convenient development experience.

## How to Play

1. Select a difficulty level.
2. Choose an empty cell on the board.
3. Enter a number from 1 to 9 using the on-screen number pad or your keyboard.
4. Use Pencil Mode to keep track of possible numbers.
5. Use the Hint button when you need help.
6. Check your entries and fill in the remaining cells to complete the puzzle.
